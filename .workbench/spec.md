# 识界 · 项目工作台定义（2026-09 修订版）

> 本修订以实际代码为准（此前 spec 停留在"CogniCard 社交化网络"早期设想，已与建成产品脱节），面向下一阶段"UI 画面与动效设计"。

## 1. 这到底是什么？

**识界是一个人的认知闭环工作台。** 用户每天把外部输入丢进素材池，AI 陪着消化，沉淀成一颗颗"知识原子"；原子会被引用、被复用、被迭代——如果太久没用，系统会提醒他"这颗原子快死了"。

闭环引擎只有一句话：

```
收集（素材）→ 消化（AI 辅助 + 主观输出）→ 沉淀（知识原子）→ 复用 / 迭代（别让知识死掉）
```

**设计红线**（后端代码注释原话）：公开的原子必须是"核心问题 + 我的观点 + 证据出处"三字段齐全；总原子数、复用次数等**一律不作为成就展示**。产品不奖励"数量"，只奖励"闭环"。

## 2. 五大模块（底部导航 L1，与现有路由一致）

### 模块一 · 工具台 `/dashboard`（默认工作台 = 每日引擎）

- 用户登录后落脚的**主界面**，也是整个产品的"每日回访页"。
- 它回答一句话：**"我的认知闭环现在停在哪儿？"**——待消化几条、知识库里沉淀了什么、哪些原子该被用起来了、最近来过什么。
- 内容：素材池（已收录 N + 导入入口）→ 消化加工（N 篇待处理，整卡可点）→ 知识库（最近沉淀 + 迭代提醒；知识库本体有"图谱 / 树 / 卡片"三档视图）→ 最近操作。
- **视觉 register**：product / 高密度 / 状态流转清晰 / 操作路径短。动效用于"状态推进"，不做装饰。

### 模块二 · 助理 `/assistant`（主动式 AI 顾问）

- 不是被动问答：它**结合认知画像主动开口**——今日建议、活跃话题、可深入的盲区；聊到有货时一键"整理成素材待沉淀"，**把对话也送回闭环**。
- 需要登录（画像跟账号走）。
- **视觉 register**：conversational AI / violet-fuchsia 暖层 / 流式输出 / "它记得你"。
- 另有通用 AI 对话 `/chat`（自带 key 的匿名工具）属于外围能力，不进主 rail。

### 模块三 · 星图 `/starmap`（看得见的认知之镜）

- 把"我的知识长什么样"做成**沉浸可视化**：拖拽旋转、滚轮缩放、点击光点进入（公开）主页。
- 有氛围系统：昼夜、季节、天气、节日（后端 weather 接口），氛围是环境不是背景装饰——可开关。
- 星星 = 原子 / 人的隐喻；连线 = 引用与弱关联。
- **视觉 register**：brand / immersive canvas / 深空暗色层——**全产品唯一的"暗色沉浸"出口**，其余页面保持亮色产品感。

### 模块四 · 消息 `/messages`

- 获赞 / 收藏 / 关注 / 评论等互动通知 + 系统提醒（如"你有 N 条素材等待消化"的月度提醒）。
- **视觉 register**：product 列表，克制、可标记已读。

### 模块五 · 我的 `/profile/me`

- 个人资料、公开主页设置、设置、会员。
- **视觉 register**：profile + 表单。

## 3. Hook（打开工具台的第一句话）

> **有 N 条素材等着消化；M 个原子已超过 90 天没被用起来。**

**为什么这样写：**
- 第一变量是**今天第一个动作**（消化队列），直指 pipeline 卡点；
- 第二变量是**资产的死活**（零复用超 90 天），它是识界区别于普通笔记的机制——知识必须被用，不能被收藏；
- 两个数字都来自现有 dashboard API，不是拍脑袋文案。

**谁在写这两个数：**

| 字段 | 谁写 | 数据来源 |
|---|---|---|
| `pending_materials` | user + assistant（导入/对话整理） | `materials.status IN (pending, digesting)` 计数 |
| `stale_atoms` | derived（后端规则计算） | `reuse_count=0` 且 90 天未更新的原子 |

**无数据时的降级（day one）：**
- 素材为空：「今天读到什么有意思的？丢进来，AI 陪你消化。」
- 无原子：「你的认知星图只有一颗种子星，第一条素材会让它发芽。」
- 无枯死原子：「你现在沉淀的每一颗原子都是活的。」← 空也说得漂亮

│   Hook 行：有 X 条素材等着消化 · M 个原子枯死       │
│   （星域随真实积累生长：沉淀的原子一颗颗亮起，      │

│    一抬头，看见自己会长成的样子）                  │
├────────────────────────────────────────────────┤
│ [导入素材]     [素材池列表]                       │
├───────────────┬────────────────────────────────┤

│ 素材 → 消化 → 沉淀 闭环推进                       │
├───────────────┴────────────────────────────────┤
│ 知识库 · 最近沉淀（列表前置，数字弱化不带光环）      │

- **移动端**：单列流 + 底部 5-tab（BottomNav 已就绪）；首屏第一眼 = **引力场窗口 Hero + 消化加工卡**，"未来会长成什么样"与"今天要做什么"同屏可见。
- **桌面端**：左侧 240px 侧栏（可收起为 64px）+ 内容居中 max-w-3xl；Hero 同构图加宽，星域更舒展。

## 5. 页面树（与现有路由对齐）

- **L1**（顺序即优先级，登录默认落工具台）：`/dashboard` 工具台 · `/assistant` 助理 · `/starmap` 星图 · `/messages` 消息 · `/profile/me` 我的

  - `/materials` 素材池 → `/materials/import` 导入 → `/materials/[id]` 素材详情 → `/materials/[id]/digest` 消化加工（阅读器 + AI 提炼 + 主观输出）

- **我的 L2**：`/profile/settings` 设置 · `/membership` 会员 · `/u/me` 自己的公开名片
- **公开层**：`/u/[userId]` 他人主页（无侧栏全屏）
- **登录**：`/`（无侧栏）

## 6. 数据模型（关键实体，供 UI 文案/状态徽标取值）

| 实体 | 关键字段 | 谁写 | 备注 |
|---|---|---|---|
| Material | status: `pending → digesting → digested/archived` | user + assistant | 消化前必读原文+主观输出（对抗假性认知） |
| Atom | status: `draft/active/archived`；核心三字段（core_question / my_view / evidence）；tags；PARA+S 分类 | user 确认 + AI 协助 | 公开原子三字段缺一自动降私有 |
| Atom 生命周期 | version、reuse_count、last_reused_at、iteration_count | derived/user | 复用与迭代是产品灵魂 |
| Reference | citer_atom → cited_atom | user | 引用溯源 `/references` |
| StarMapWeather | season / weather / festival / preference | system（integration） | 氛围层，可开关 |
| Notification | type（互动/待消化提醒）、read | system | 月度"待消化"提醒已存在 |
| Assistant profile | active_topics / strengths / weaknesses | derived（AI） | 助理画像 |
| Membership | level、ai_quota、price | system + payment | 单档付费 |

## 7. UI 画面与动效基调（本次任务核心）

**灵魂：一抬头，看见自己会长成的样子。** 工具台首页顶部的「引力场窗口」把"积累的未来"直接画出来——每沉淀一颗原子，星域就亮起一颗星；但生长是过程不是奖杯，任何数字永不炫技。

### 分层 register（决定动效的"配比"）

| 层 | 页面 | 基调 | 动效预算 |
|---|---|---|---|
| 效率层（product） | 工具台正文 / 素材池 / 消息 / 我的 | 月白浅色、高密度、indigo | 只做**状态推进与到场**：数量变化轻动、消化状态流转、进入页面的短位移，全部 ≤200ms |
| Hero 引力场层 | 工具台 `/dashboard` 首屏顶部 | **有界的深空窗口**：星域 + 月白舱体过渡 | 中等：星点逐一亮起、素材光点划入、暗座轮廓浮现——是"窗口"不是"大屏"，永不抢正文操作位 |
| 对话层（AI） | 助理 | violet-fuchsia、暖、留白多 | **流式打字**是主角；开场时"画像认知"可做轻浮现 |
| 沉浸层（brand） | 星图 | 全屏深空 canvas + 氛围 | 可以**大胆**：星点生长、连线脉冲、昼夜/季节切换、入场镜头——这是产品"被看见"的情感出口 |

### 首页引力场窗口（`/dashboard` Hero，本次 craft 落地）

工具台是用户进入识界的第一画面——它要"惊艳 + 让他喜欢 + 对未来的自己产生畅想"。做法不是特效，而是**把数据画成未来**：

- **构图**：深空渐变窗口（桌面高约 280px / 移动约 200px，圆角 24、有界），与月白正文区形成"透过舷窗看见自己的宇宙"的对景。
- **星域规则（Canvas，全部真实数据驱动）**：
  - 已沉淀原子 → 一颗颗**点亮的星**（数量 = min(atomTotal, 上限)），越攒越亮；
  - 未沉淀的认知潜能 → **暗座/虚线圈**（占位星座），暗示"这里会长出星"；
  - 待消化素材（pending/digesting）→ 缓缓**划入的光点**（素材流），落定即亮；
  - 桌面多一条细小的"光路/轨道"暗示引用关系在长成。
- **文案**：右上小标「我的知识宇宙」；Hook 行进 Hero：`有 X 条素材等着消化 · M 个原子枯死`，冷启动时降级为种子星文案。
- **反 slop 边界**：这是工具台唯一暗色出口，窗口有界、不蔓延正文；与星图（全屏沉浸）在"尺度"上分开。

### 知识库三档视图（`/atoms`，代码已实现，文档补记）

知识库不是单一样式——同一份原子资产提供三档视图，**默认图谱并记住用户上次选择**（localStorage 持久化）：

1. **图谱**（graph，默认）：Obsidian Graph View 式力导向——PARA → 标签 → 原子三层发散，点节点出详情面板。这是知识库的"联想/结构"档：**亮底发散可视化**。注意：它不是星图——星图是暗色认知星系氛围层，两者视觉边界必须分开。
2. **知识树**（tree）：左侧 PARA 目录树 + 当前分支叶子卡片 + 面包屑回退 + 树内穿透搜索。"浏览复盘"档。
3. **卡片平铺**（flat）：全量卡片网格 + 搜索/筛选/排序 + 批量整理（导出 / 移动分类 / 归档 / 删除）。"录入与整理"档，纯效率层。

三档共享同一份数据（树/图谱取全量、卡片可筛选），它们只是**看同一座山的三种走法**，不是三种知识。

**动效分配**：图谱档 = 可视化层中等预算（节点入场连线、力导向拖拽、详情浮现，仍禁止计数炫技）；树 / 卡片档 = 效率层 ≤200ms；三档间切换给统一、克制的过渡语言，表达"换个走法"而非炫技。

### 反 slop（禁止清单）
- 原子数 / 复用次数 / 闭环率等数字**禁止**做成大数字滚动、光环、进度环炫技（产品红线：数量不作成就）。
- 工具台正文区**禁止**背景粒子/星尘干扰专注；暗色只允许出现在首页顶部**有界的引力场窗口**里，星空仍属于星图。
- 引力场窗口的星域必须由真实数据驱动（原子点亮、素材划入），禁止与数据无关的装饰粒子；它是"窗口"不是"大屏"，永不越过窗口边界。
- 星图**禁止**假 3D 地球或与数据无关的粒子秀；每颗星、每条线必须有真实来源（原子/引用/用户）。
- 知识库图谱档展示的是"关系与结构"，禁止把节点做成计数勋章。
- 助理**禁止**做成通用 ChatGPT 外观，开场必须带用户画像痕迹（"你上次聊到 X"）。
- 空状态必须有下一步动作按钮，禁止只写"暂无数据"。

### 动效锚点（供 finesse-ui 落地）
1. **引力场窗口入场**：原子星随加载逐一点亮、暗座轮廓浮现、待消化素材如光点缓落——"你的未来正在成形"。
2. 工具台 Hook 行的数字变化：新旧数字的过渡（不是炫耀，是"今天少了一件事"的踏实感）。
3. 素材状态 `pending → digesting → digested` 的徽标流转。
4. 助理"整理成素材"成功后 → 跳转 digest 前的成功态（形成闭环感）。
5. 星图入场：加载 → 星点逐一发光；昼夜氛围淡入。
6. 知识库三档切换（图谱 → 树 → 卡片）的过渡：克制、一致。
7. 移动端底部 tab 切换的指示动效（克制版）。

## 8. 变现切口

单档会员（`/membership` 已建）：免费层有基础素材/原子配额；付费解锁 **AI 辅助提炼每月配额**、无限制素材存储、批量导出。付费意愿随管道变深而增强——用户在消化里尝到 AI 甜头后，配额触顶即自然转化。**变现不在工具台做推销 UI**，放在 `/membership` 与配额用尽的克制提示里。

- 现有实现**已经满足大量 spec**：不推倒重来，做"引力场窗口 Hero + 分层动效 + 首屏 Hook 化 + 星空与工具台的视觉边界"即可。
- 工具台首页改造优先级：① **引力场窗口 Hero**（首屏惊艳 + 未来感，数据驱动星域）→ ② Hook 行与文案进入 Hero → ③ 消化加工卡升为视觉焦点 → ④ 知识库数字弱化、列表前置 → ⑤ 迭代提醒进入 Hook 语境。
- 星图已有 Canvas 与氛围数据；首页只加**有界**的引力场窗口（新 Canvas 小组件），不要把星空蔓延进正文与其它页面。
- 全程遵守"数量不作成就"红线：任何"涨数字"的动效一律不做。
