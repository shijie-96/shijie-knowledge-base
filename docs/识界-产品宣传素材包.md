# 一、产品分析

## 1.1 一句话定位

> **识界是一个人的认知闭环工作台——把外部输入，沉淀成可复用、会迭代、能被看见的知识原子。**

## 1.2 核心闭环（产品引擎）

```
收集（素材池） → 消化（主观输出不可跳过） → 沉淀（知识原子） → 复用 / 迭代（别让知识死掉）
```

| 环节 | 落地界面 | 真实机制 |
|---|---|---|
| 收集 | `/materials` · `/materials/import` | 聊一聊 / 粘贴链接 / 上传文件 三种入口；URL 自动抓正文降噪，PDF/Word/Markdown/图片/音视频解析 |
| 消化 | `/materials/[id]/digest` | **强制二选一主观输出** + 实时敷衍识别；原文可划词引用到思考区；可「暂不消化」退回 |
| 沉淀 | `/atoms/[id]` | 核心三字段（核心问题 / 我的观点 / 事实佐证）+ 版本历史 + 引用关联 + PARA+S 分类 |
| 复用/迭代 | `/atoms` · `/atoms/iterate` · `/references` | 复用/引用/迭代计数、迭代提醒、引用溯源网络 |

## 1.3 目标用户

| 人群 | 痛点 | 识界的解法 |
|---|---|---|
| **知识工作者 / 研究者** | 收藏了很多，从没变成自己的东西 | 素材不消化就不能沉淀；"它还不是你的知识" |
| **终身学习者 / 读书人** | 读完就忘，笔记沉睡 | 强制主观输出 + 90 天零复用提醒 |
| **内容创作者 / 独立开发者** | 想法散落各处，难成体系 | PARA+S 分类 + 引用网络把观点缝起来 |
| **重视数据主权的人** | 平台锁定，知识带不走 | 全量导出 Markdown + HTML + JSON，AI 记忆可导出可一键清除 |

**共同特征**：不满足于"存下来"，在意"真的想明白了，并且用得上"。

## 1.4 差异化卖点（4 条，全部有代码支撑）

1. **对抗假性认知**——消化环节强制二选一主观输出，AI 不能代笔，不可跳过；输入"不错""有收获""666"会被实时识别并拦截。
2. **素材与认知物理分离**——素材池只是原始输入，不向量化、不公开、不可直接分享导出；必须经消化才能成为认知资产。
3. **不奖励数量，只奖励闭环**——复用率 / 迭代率 / 被引用才是主角；成长看板只呈现客观行为数据，明确写着"不评分、不排名"。
4. **主动式 AI 助理**——不是被动问答，它读你的认知画像后主动开口，还会在你说得前后不一致时主动挑战你。

# 三、产品宣传文案

## 3.1 主标题

> # 识界
> ### 把读过的，变成想明白的

**备选**：
- 收藏不是学会，识界让它真正变成你的
- 别让知识死在收藏夹里

## 3.2 副标题

> 一个人的认知闭环工作台——从收集、消化到沉淀、复用，
> 每一条输入都要过你自己的脑子，才会成为你的知识原子。

**短版（适合海报/应用商店）**：
> 收集 · 消化 · 沉淀 · 复用。对抗假性认知，让知识真的长在你身上。

## 3.3 五条核心卖点

**① 不写完自己的思考，就存不进去**
消化环节强制二选一：写下「核心启发」，或说清「我同意还是反对、为什么」。AI 不代笔，这一步不能跳过——这是对抗假性认知的核心。

**② 它会当场拆穿你的敷衍**
输入"不错""有收获""666"？系统会实时提示：内容过短、检测到可能敷衍的表达。低质量的感动，进不了你的认知资产。

**③ 素材是原料，认知才是资产**
素材池只是原始输入，不向量化、不公开、不能直接分享导出——必须经消化加工，才会沉淀成你的知识原子。"它还不是你的知识。"

**④ 知识不用，就会死掉**
零复用超过 90 天、高复用久未迭代，系统会主动提醒你：该用了，该迭代了。识界不奖励你存了多少，只关心闭环有没有跑起来。

**⑤ 你的知识，随时能带走**
全量导出 Markdown + HTML + JSON，离线可浏览、不依赖平台；AI 记忆也能一键导出或彻底清除。数据完全属于你。

## 3.4 使用场景

**场景一 · 读完一篇好文章**
复制链接丢进素材池 → 打开沉浸式阅读器，划下那句击中你的话 → 写下"它改变了我的什么认知" → 保存，沉淀成一颗知识原子。

**场景二 · 脑子里有个模糊的想法**
素材池选「聊一聊」，想到哪说到哪，AI 顺着追问细节 → 聊完自动整理成结构化素材 → 走消化，落到你的知识库。

**场景三 · 三个月后，系统提醒你**
"这颗原子已经 90 天没被用起来了。"点开迭代提醒，复用它、合并它，或承认它该归档了。

**场景四 · 助理主动找你**
"你上次的观点和前天的说法不太一致。"认知助理结合你的画像主动开口，能追问、能挑战、还能把这一轮对话整理成素材，送回闭环。

**场景五 · 把知识连成网**
在别人的公开原子上点「引用」，观点就缝进了你的知识网络；打开引用溯源，看清自己的认知是怎么层层长起来的。

## 3.5 结尾行动号召

> **别再让"收藏"冒充"学会"。**
> 今天丢进第一条素材，让 AI 陪你消化，
> 写下第一句真正属于你自己的思考。
>
> **—— 识界 · 认知无界，成长无限**

**按钮文案**：`开启我的认知闭环` / `导入第一条素材`
