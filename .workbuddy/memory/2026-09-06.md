### 踩坑：Next dev server 卡死

- 现象：改完代码页面不更新，且 `GET /dashboard 404`、`/_next/static/chunks/app/page.js 404`
- 根因：`frontend-dev-err.log` 里 Watchpack 在扫 `D:\` 根目录（`EINVAL: invalid argument, lstat 'D:\pagefile.sys'` / `DumpStack.log.tmp`），文件监听失效 → 不再重新编译
- 解法：停进程 → 删 `frontend/.next`（237M 构建缓存，可再生成）→ 重启 `npm run dev`
- 注意：Windows 原生 curl 的 `/tmp/x.html` 会解析成 `C:\tmp\`，而 Git Bash 的 `/tmp` 是别处；**抓页面要 `cd /tmp` 后用相对文件名**
